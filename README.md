# 电商平台 React Native 应用

## 项目简介

这是一个基于 React Native 和 Expo 框架开发的电商平台移动应用，包含采购管理、供应商管理、商品管理和个人中心等核心功能模块。

## 技术栈

- React Native
- Expo
- React Navigation 6+
- TypeScript
- React Hooks
- StyleSheet API
- FlatList

## 项目结构

```
src/
├── navigation/           # 导航配置
│   ├── RootNavigator.tsx     # 根导航器
│   ├── TabNavigator.tsx      # 底部标签导航
│   └── HomeStackNavigator.tsx # 首页导航栈
├── screens/              # 页面组件
│   ├── Home/               # 首页模块
│   ├── Procurement/        # 采购模块
│   ├── Supplier/           # 供应商模块
│   ├── ProductList/         # 商品列表
│   ├── ProductDetail/       # 商品详情
│   └── Profile/             # 个人中心
└── types/                # TypeScript 类型定义
    └── index.ts           # 类型定义文件
```

## 功能模块

### 1. 首页模块 (HomeScreen)

- **顶部横幅**：显示欢迎信息和平台标语
- **采购管理模块**：
  - 采购计划：导航到采购计划页面
  - 采购订单：导航到采购订单页面
  - 入库管理：导航到入库管理页面
- **供应商管理模块**：
  - 供应商列表：导航到供应商列表页面
  - 供应商评价：导航到供应商评价页面
  - 联系供应商：导航到联系供应商页面
- **商品管理模块**：
  - 商品列表：导航到商品列表页面
  - 热门商品：占位功能
  - 库存管理：占位功能
- **推荐商品预览**：显示推荐商品并导航到商品列表页面
- **底部信息**：显示版权信息

### 2. 采购模块

#### 2.1 采购计划 (ProcurementPlanScreen)

- **新建计划按钮**：位于页面顶部右侧，点击可新建采购计划
- **采购计划列表**：显示所有采购计划，每个计划包含：
  - 计划名称
  - 计划状态（进行中、待审批、已完成）
  - 总金额
  - 创建日期
- **计划统计**：显示计划相关统计信息：
  - 总计划数
  - 计划总金额
  - 进行中计划数

#### 2.2 采购订单 (PurchaseOrderScreen)

- **新建订单按钮**：位于页面顶部右侧，点击可新建采购订单
- **采购订单列表**：显示所有采购订单，每个订单包含：
  - 订单编号
  - 订单状态（已下单、已发货、已完成）
  - 供应商名称
  - 总金额
  - 商品数量
  - 创建日期
- **订单统计**：显示订单相关统计信息：
  - 总订单数
  - 订单总金额
  - 未完成订单数

#### 2.3 入库管理 (WarehouseEntryScreen)

- **新建入库按钮**：位于页面顶部右侧，点击可新建入库记录
- **入库记录列表**：显示所有入库记录，每个记录包含：
  - 入库编号
  - 入库状态（已入库、待入库）
  - 订单编号（关联的采购订单）
  - 供应商名称
  - 总金额
  - 商品数量
  - 入库日期
- **入库统计**：显示入库相关统计信息：
  - 总入库单
  - 入库总金额
  - 已完成入库

### 3. 供应商模块

#### 3.1 供应商列表 (SupplierListScreen)

- **添加供应商按钮**：位于页面顶部右侧，点击可添加新供应商
- **供应商列表**：显示所有供应商信息，每个供应商包含：
  - 供应商名称
  - 评分
  - 联系人姓名
  - 联系电话
  - 联系邮箱
  - 供应商状态（活跃/非活跃）
  - 供应商分类
- **供应商统计**：显示供应商相关统计信息：
  - 总供应商数
  - 活跃供应商数
  - 平均评分

#### 3.2 供应商评价 (SupplierEvaluationScreen)

- **新建评价按钮**：位于页面顶部右侧，点击可新建供应商评价
- **评价列表**：显示所有供应商评价，每个评价包含：
  - 供应商名称
  - 评分
  - 评价人
  - 评价日期
  - 评价内容
  - 分类评分（产品质量、交货及时性、服务态度、价格合理性）
- **评价统计**：显示评价相关统计信息：
  - 总评价数
  - 平均评分
  - 评价供应商数

#### 3.3 联系供应商 (ContactSupplierScreen)

- **供应商联系信息展示**：显示所有供应商的详细联系信息，每个供应商包含：
  - 供应商名称
  - 联系人列表（姓名、职位、电话、邮箱）
  - 首选联系人标记
  - 公司地址
  - 官方网站
- **联系人操作**：
  - 拨打电话按钮：点击可拨打联系人电话
  - 发送邮件按钮：点击可发送邮件给联系人
- **网站访问**：点击官方网站链接可访问供应商网站

### 4. 商品模块

#### 4.1 商品列表 (ProductListScreen)

- **商品列表展示**：显示所有商品，每个商品包含：
  - 商品图片
  - 商品名称
  - 商品价格
  - 商品描述
- **商品详情导航**：点击商品卡片可导航到商品详情页面
- **滚动加载**：使用FlatList实现商品列表的滚动加载

#### 4.2 商品详情 (ProductDetailScreen)

- **商品信息展示**：显示商品的详细信息，包括：
  - 商品图片
  - 商品名称
  - 商品价格
  - 商品描述
  - 商品详情（品牌、产地、库存、保修）
- **加入购物车功能**：点击"加入购物车"按钮可将商品加入购物车
- **查看购物车功能**：点击"查看购物车"按钮可查看购物车内容
- **返回功能**：通过导航栏的返回按钮可返回商品列表页面

### 5. 个人中心 (ProfileScreen)

- **用户信息展示**：显示用户的基本信息，包括：
  - 用户头像
  - 用户名
  - 用户邮箱
  - 编辑资料按钮
- **订单管理**：显示订单相关的快捷入口，包括：
  - 待付款
  - 待发货
  - 待收货
  - 待评价
  - 查看全部订单按钮
- **个人服务**：显示个人相关的服务入口，包括：
  - 我的优惠券
  - 我的收藏
  - 浏览历史
  - 收货地址
- **其他设置**：显示其他设置选项，包括：
  - 设置
  - 帮助中心
  - 联系客服
- **退出登录**：点击可退出当前账号
- **版本信息**：显示当前应用版本号

## 类型定义

项目使用 TypeScript 进行类型定义，所有类型定义位于 `src/types/index.ts` 文件中，包括：

- `Product` - 商品类型
- `ProcurementPlan` - 采购计划类型
- `PurchaseOrder` - 采购订单类型
- `WarehouseEntry` - 入库记录类型
- `Supplier` - 供应商类型
- `SupplierContact` - 供应商联系人类型
- `SupplierWithContacts` - 供应商联系信息类型
- `SupplierEvaluation` - 供应商评价类型
- `RootStackParamList` - 根导航栈参数类型
- `HomeStackParamList` - 首页导航栈参数类型
- `TabParamList` - 标签导航参数类型

## 运行项目

### 前提条件

- Node.js 16+
- npm 或 yarn
- Expo CLI

### 安装依赖

```bash
npm install
```

### 运行项目

#### Web 版本

```bash
npm run web
```

#### iOS 版本

```bash
npm run ios
```

#### Android 版本

```bash
npm run android
```

### 开发服务器

```bash
npx expo start
```

## 开发注意事项

1. **TypeScript**：项目使用 TypeScript 进行开发，所有新增代码都需要添加类型定义

2. **导航**：使用 React Navigation 6+ 进行导航，所有导航参数都需要在类型定义文件中声明

3. **样式**：使用 StyleSheet API 进行样式定义，遵循组件化开发原则

4. **数据**：当前项目使用模拟数据，实际开发中需要连接后端 API

5. **性能**：对于列表数据，使用 FlatList 进行渲染，确保性能优化

6. **测试**：开发过程中需要进行跨平台测试，确保在 iOS 和 Android 上都能正常运行

7. **依赖管理**：使用 Expo 推荐的依赖管理方式，避免使用不兼容的依赖

## 项目扩展

1. **后端集成**：连接真实的后端 API，替换模拟数据

2. **状态管理**：引入 Redux 或 Context API 进行全局状态管理

3. **网络请求**：添加 axios 或 fetch 进行网络请求封装

4. **本地存储**：使用 AsyncStorage 或 SecureStore 进行本地数据存储

5. **推送通知**：集成 Expo Notifications 实现推送通知功能

6. **支付集成**：集成支付 SDK 实现支付功能

7. **多语言**：添加 i18n 支持，实现多语言切换功能
